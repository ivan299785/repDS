## Проект 1: Предсказание длительности поездок такси

**Файл:** [`Project-5._Ноутбук-шаблон.ipynb`](Project-5._Ноутбук-шаблон.ipynb)

**Бизнес-задача:** разработать модель для прогнозирования длительности поездок
такси в Нью-Йорке для автоматизации расчёта стоимости и оптимизации
бизнес-процессов таксопарков.

**Техническая задача:** построить регрессионную модель машинного обучения,
предсказывающую время поездки (в секундах) на основе характеристик клиента,
времени, географии и погодных условий.

### Данные
- `train.csv` — NYC Taxi Trip Duration, более 1.5 млн поездок, 11 признаков.
- `weather_data.csv` — погодные данные по часам.
- `holiday_data.csv` — даты праздников.
- `osrm_data_train.csv` — расстояние, время в пути, число шагов по маршруту (OSRM API).

### Этапы работы
1. **Подготовка данных** — объединение таблиц, обработка пропусков
   (медиана по дате для погоды, общая медиана для OSRM, `'None'` для явлений).
2. **Feature Engineering** — временные (`pickup_date`, `pickup_hour`,
   `pickup_day_of_week`, `pickup_holiday`), географические
   (`haversine_distance`, `direction`, `geo_cluster` через KMeans на 10 кластеров),
   OSRM-признаки, погода.
3. **Очистка данных** — удалены поездки >24 часов (4 записи) и «телепортации»
   со средней скоростью >300 км/ч (407 записей). Целевая переменная
   логарифмирована: `trip_duration_log = log(trip_duration + 1)`.
4. **EDA** — распределение целевой переменной, тест Д'Агостино
   (распределение `trip_duration_log` не нормальное, p-value < 0.05),
   анализ зависимостей час × день недели, геокластеры.
5. **Модели** — Linear / Ridge / Lasso / Elastic Net, Random Forest,
   Gradient Boosting, XGBoost, LightGBM.
6. **Валидация** — RMSLE, 5-fold CV, 80/20 split, GridSearchCV.

### Результаты

**Лучшая модель:** Gradient Boosting.

| Метрика | Train | Validation |
|---|---|---|
| **RMSLE** | 0.37 | 0.39 |

**Топ-3 признака:** `total_distance`, `total_travel_time`, `pickup_hour`.

### Выводы
- Геоданные и OSRM-признаки дают наибольший вклад в качество модели.
- Логарифмирование целевой переменной стабилизирует распределение
  и соответствует метрике RMSLE.
- Временные и погодные признаки добавляют полезный сигнал.
- Предобработка выбросов заметно улучшает обучение.
