# Анализ вакансий из HeadHunter

Проект по анализу данных: исследование базы вакансий с HeadHunter
с помощью SQL и Python. Цель — понять структуру данных, выявить
закономерности рынка труда и подготовить основу для будущей
ML-модели, рекомендующей вакансии соискателям на позицию Data Scientist.

## О проекте

**Контекст:** работа в кадровом агентстве, подбирающем вакансии
для IT-специалистов. Первый этап ML-проекта — Data Understanding:
разобраться, что представляют собой данные и насколько они
соответствуют целям рекомендательной модели.

**Бизнес-задача:** понять, какие факторы влияют на привлекательность
вакансий для соискателей Data Scientist, и подготовить данные
для будущего рекомендательного алгоритма.

**Техническая задача:** провести разведывательный анализ базы вакансий
HeadHunter через SQL-запросы и визуализации, сформулировать гипотезы
и подготовить очищенный набор данных.

## Данные

Все таблицы находятся в схеме `public` базы данных `project_sql`
(PostgreSQL).

| Таблица | Содержание |
|---|---|
| `vacancies` | Вакансии: название, регион, работодатель, тип занятости, расписание, требуемый опыт, зарплатная вилка |
| `areas` | Справочник регионов: код и название |
| `employers` | Справочник работодателей |
| `industries` | Справочник сфер деятельности работодателей |
| `employers_industries` | Связь «работодатель ↔ сфера деятельности» |

**Зарплатная вилка** — верхняя и нижняя граница оплаты труда в рублях
(зарплаты в других валютах переведены в рубли).

## Этапы работы

### 1. Предварительный анализ
- Общее число вакансий, работодателей, регионов и сфер деятельности.
- Первичная оценка полноты данных.

### 2. Детальный анализ вакансий
- Распределение вакансий по регионам.
- Заполненность полей с зарплатой.
- Средние значения зарплатных вилок.
- Типы рабочего графика и трудоустройства.
- Требуемый опыт работы.

### 3. Анализ работодателей
- Топ работодателей по числу вакансий.
- Регионы по количеству работодателей и вакансий.
- География публикаций вакансий у крупнейших работодателей.
- Сферы деятельности работодателей.

### 4. Предметный анализ (Data Science)
- Вакансии, связанные с данными.
- Вакансии для начинающих дата-сайентистов.
- Популярность ключевых навыков (SQL, Python).
- Средняя зарплата DS-специалистов с разным опытом.

## Ключевые выводы

### Предварительный анализ
- В базе **49 197 вакансий**, **23 501 работодатель**, **1 362 региона**
  и **294 сферы деятельности**.

### Детальный анализ вакансий
- Больше всего вакансий — в **Москве, Санкт-Петербурге, Минске,
  Новосибирске и Алматы**.
- Средняя нижняя граница зарплаты — **~71 065 руб.**,
  верхняя — **~110 537 руб.**
- Самый популярный тип занятости — **полная занятость**,
  часто в формате **удалённой работы**.

### Анализ работодателей
- Топ по числу вакансий: **Яндекс, Ростелеком, Тинькофф, СБЕР,
  Газпром нефть**.
- **Яндекс** публикует вакансии в **181 регионе**.

### Предметный анализ (Data Science)
- **1 771 вакансия** связана с данными.
- Для начинающих дата-сайентистов доступно **51 вакансия**.
- **Python** указан в **357** вакансиях по DS, **SQL** — в **229**.
- Средняя зарплата DS-специалистов с опытом **3–6 лет** —
  **~243 115 руб.**
